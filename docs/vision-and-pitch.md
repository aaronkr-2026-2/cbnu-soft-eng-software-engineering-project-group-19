# Week 2–3: Idea, stack, and product vision

## Project pitch

Many self-directed learners can find learning material but have trouble following a course consistently and demonstrating that they completed it. StudyFlow AI brings course discovery, structured lessons, progress tracking, quizzes, a final exam, and verifiable certificates into one learning flow. It supports Uzbek, English, Russian, and Korean so learners can use the interface in their preferred language.

## Intended audience

Independent learners taking structured, self-paced courses; course authors who need to publish lessons and quizzes; and organizations that need to verify a learner's certificate.

These audience descriptions are initial product assumptions, not results of completed user research.

## Product vision statement

For independent learners who want to study at their own pace and demonstrate course completion, StudyFlow AI is a multilingual learning platform that guides them from course selection through lessons and assessment to a publicly verifiable certificate. It combines a learner dashboard, course authoring, progress tracking, quizzes, and certificate verification in one application.

## Initial value proposition

A learner can see what to study next and how far they have progressed; an author can create a complete course with lesson quizzes; and a third party can check a certificate without creating an account.

## Technology selected

- Python and FastAPI for the API and serving the web interface.
- PostgreSQL for persistent user, course, enrollment, progress, quiz, and certificate data.
- SQLAlchemy and Alembic for data access and schema migrations.
- HTML, CSS, and browser JavaScript for a dependency-free interface.
